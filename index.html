Daily Jobs

Your jobs are saved in your own Google Sheet, so every phone or computer you connect shows the same list.

  1. Create a blank Google Sheet.
  2. Open Extensions › Apps Script, paste the code from code.gs, and change the SECRET line to a password you choose.
  3. Choose Deploy › New deployment › Web app. Set Execute as to Me and Who has access to Anyone, then deploy.
  4. Paste the Web app URL and your secret below.

Already connected on another device? Open the link from its Copy link for other devices button instead of filling this in.
